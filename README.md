# FitnessLibrary

### Android App Development Mini Project

## About the Project

**FitnessLibrary** is an Android application developed as part of an Android App Development Mini Project.

The project focuses on building a fitness-related mobile application using Android development technologies. It provides a foundation for organizing fitness information and delivering a simple, user-friendly mobile experience.

## Project Objectives

- Develop a functional Android application.
- Design a simple and user-friendly interface.
- Apply Android application development concepts.
- Understand activity lifecycles and navigation.
- Gain practical experience with Android Studio and Gradle.

## Technologies Used

- **IDE:** Android Studio
- **Platform:** Android
- **Build System:** Gradle
- **Version Control:** Git
- **Repository Hosting:** GitHub

## How to Run the Project

1. Install **Android Studio**.
2. Clone the repository:

   ```bash
   git clone https://github.com/aniketsen9/Android_AppDev_Mini_Proj.git
   ```

3. Open Android Studio.
4. Select **Open**.
5. Navigate to the `FitnessLibrary 2` folder.
6. Allow Gradle to sync the project.
7. Connect an Android device or start an Android emulator.
8. Click **Run** to launch the application.
